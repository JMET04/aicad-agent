# CAD 修改器交互契约 v2

## 面向用户的唯一流程

用户只需要完成三件事：选择对象、修改数值或用自然语言说明要求、检查同一份“修改清单”。系统内部仍会把清单转换为绑定源文件哈希、精确语义引用、作用范围和保持策略的事务，但这些实现细节默认折叠在“高级信息”中。

这不是取消精确事务，而是取消让用户手工理解两套概念。未经精确转换和完整依赖重放的自然语言说明仍不得直接修改 CAD。

## 自由截面

- 支持 `X=10`、`Y=-5`、`Z=12` 等轴向平面。
- 支持“法向 1,1,0 过原点”和“法向 1,2,3 过点 4,5,6”等任意平面。
- 法向量必须有限且非零，内部归一化；过点使用模型毫米坐标。
- 截面由受约束特征运算体与平面的交线生成，不从图片像素估算。
- 点击截面线选择的是该特征的精确参数控制引用；截面代理本身不冒充宿主 CAD 的持久 BREP 名称。
- 自由截面用于审查、定位和发起修改。量产或制造判断仍需 AutoCAD/SolidWorks 等宿主对最终实体重开复核。

## 隐藏关键几何

几何中心、中心轴、阵列分布圆、相反轮廓边和竖向交界边属于关键几何。它们默认透明，命中层始终存在；鼠标悬停或选中后才显示。可见线宽与点击容差必须分离，避免为了好点选而把 CAD 线画粗。

每个关键几何必须绑定稳定的 `feature_id|semantic_subobject` 引用。若只有投影或派生代理，界面必须明确其参数代理身份，不能宣称它具有原生拓扑权威。

## 核心参数

每个特征在右侧面板公开全部独立设计参数：中心、宽度、高度、半径、阵列数量、分布圆半径、起始角和深度（按特征实际类型取子集）。点击参数必须同时：

1. 选中对应的精确语义控制引用；
2. 在快速修改区显示中文参数名和当前值；
3. 生成带作用范围、影响实例数和必要保持策略的精确操作；
4. 经过完整特征图重放和产品不变量检查后才允许输出候选结果。

## 本次错误的根因

旧版把系统内部“自然语言候选”和“可执行精确事务”直接做成两个用户步骤，造成重复按钮、重复草稿和术语负担。固定 `X=0/Y=0` 截面被写死在视图目录中，没有把平面建模成可输入对象；中心与交界几何也没有独立命中层；参数只是技术路径下拉项，没有成为可浏览的审查对象。

## 永久预防规则

- UI 只能有一份用户可见修改清单；精确事务默认折叠，但不得省略。
- 任意三维审查器必须接受“法向量 + 过点”的自由截面，轴向表达只是快捷语法。
- 关键几何必须同时通过“默认隐藏、悬停显形、点击可选、精确引用”四项浏览器测试。
- 核心参数目录必须由已编译特征生成，禁止手写遗漏，禁止使用图片像素作为尺寸真值。
- 每次发布必须真实浏览器验证轴向截面、斜截面、截面点选、中心点关系、参数回填、UTF-8 和横向溢出。
