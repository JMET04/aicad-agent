## 制造前成本与可用性门禁

- 新增只读MCP `aicad_validate_procurement_preflight`、源CLI和打包CLI `procurement-preflight`。
- 完整交付物成本覆盖PCB、准确MPN元件、外部配件、机械、装配、运输、税费与工具；未知不能按0，免费PCB不抵偿整套缺价。支持真实明确接受的裸板范围，不强迫普通绘图或只读询价通过采购审批。
- 检查MOQ、采购倍数、库存、价格时效、来源快照、兼容替代资格与独立预算记录；绑定设计/库存/报价与具体动作，改变后旧接受失效。
- 分离host逻辑、模拟电路、装配分析和真实硬件证据。按实际观测核指标并保留模型限制和首件义务；直接检查冻结Kconfig，不允许算法测试通过覆盖CONFIG_BT=n。
- 用户终止/暂停项目后阻断采购动作，不因旧订单、优惠券或测试通过恢复。
- 制造候选显式标记采购检查仍必需，不授予订单权限。技能入口与事故复盘同步更新，包含运行30项固件host测试后识别默认无线/声音/校准未闭合的真实反例。

所有采购/支付/用券、真实硬件功能和生产授权字段保持false。门禁只验证记录一致性，不认证人类/供应商、不自动下单，不拦截外部手工浏览器旁路；工程规则、CAM、实际功能与专业放行仍是独立边界。
