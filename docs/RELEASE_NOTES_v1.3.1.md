# aicad-agent v1.3.1

本版本把 CAD 生成顺序升级为不可跳过的三级硬门禁：

1. 整体用户要求一致性；
2. 细节数学可靠性；
3. 隔离候选构建与 SHA-256 审计。

## 重点更新

- 新增需求契约与证据追踪 JSON Schema；
- 每条硬要求新增 `actualBinding`，验证器强制 `boundActual = observed = expected`；
- 新增产品类型、结构族、上下闭合、主要功能和尺寸权威检查；
- 新增 PKG-G024、PKG-G025、LESSON-017、LESSON-018；
- 新增正常性模板和独立雅可比秩证明；
- 新增上部插舌/下部自动锁底的类型化非镜像默认模板；
- 新增完整面、端点归属、单闭合轮廓和耦合参数域门禁；
- 新增边、角、面标号与双线关系菜单的交互修改器；
- 新增受控输出脚本，前级失败时不读取后级输入、不生成候选 CAD；
- 新增“追踪值 120、实际实例 121”必定失败的回归测试。

## 发布验证

- 根级测试：34 项通过；
- 独立插件发布目录：31 项通过；
- 安装集成缓存：56 项通过；
- 默认插锁盒样例：整体要求 12/12、实际绑定 12/12、细节硬门禁 8/8；
- 实例独立秩 144/144、剩余自由度 0；
- 255 组参数域案例通过；
- 六种候选工件通过哈希审计。

## 安全边界

`reviewOnly=true`、`accepted=false`、`ruleEnabled=false`、`packagingGated=true`。

这是工程候选版本，不声明量产、材料强度、设备公差或技术验收。
