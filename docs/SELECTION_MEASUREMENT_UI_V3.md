# CAD 修改器：选中对象即时测量契约 v3

## 用户看到什么

右侧“几何数值”只回答当前选中对象的问题，不再让用户从整张图的核心参数目录中猜测：

- 选择直线：显示模型长度、起点 XYZ、终点 XYZ；若该长度由宽度、高度或深度控制，可点击数值直接回填编辑器。
- 选择点：显示模型坐标 X、Y、Z；参数化中心点可点击后直接编辑 X、Y。
- 选择圆：显示半径、直径和圆心 XYZ；可点击半径直接回填编辑器。
- 选择面：显示面积和几何中心，仍保持审查用途，不冒充宿主 CAD 的原生 BREP 拓扑名称。

“核心参数”仍保留，用于浏览整个特征的设计变量；“几何数值”则是当前选择的即时测量。两者职责不同，不能再互相替代。

## 数学和坐标权威

每个选择引用必须携带严格类型的 `measurement`：

- `line`: `length_mm`、`start[3]`、`end[3]`；
- `point`: `coordinates[3]`；
- `circle`: `center[3]`、`radius_mm`、`diameter_mm`；
- `face`: `center[3]`、`area_mm2`。

数值由约束求解后的二维实体或已编译三维特征计算，坐标统一绑定右手笛卡尔坐标系 `MODEL_XYZ`，单位为毫米。屏幕像素、缩放比例和透视投影不得成为尺寸真值。正投影或辅助代理必须明确标注权威等级。

## 坐标系开关

顶栏“坐标系”开关默认开启，并同步控制：

1. 每个二维、正投影和截面视图中的轴标；
2. 每个视图中的模型原点标记；
3. 可旋转三维选择器中随视角旋转的 X/Y/Z 三轴。

关闭时三类坐标基准必须一起隐藏，重新开启必须一起恢复。不得出现按钮状态变化但画布仍显示坐标轴的假开关。

## 本次错误根因

上一版把“特征的核心参数目录”误当成“选中对象的直接测量结果”。因此右侧虽然能看到宽度、半径等参数，但用户点击一条具体边、一个点或一个圆时，没有建立 `selection reference → compiled measurement → visible card` 的数据链。矩形轮廓第 1/3 边还错误绑定到高度路径，暴露出按编号手写边—参数关系而没有用端点方向复核的问题。

## 永久预防规则

- `SUB-G016`：每个可选对象必须有严格类型的编译模型测量；线、点、圆、面分别执行字段完整性检查，并在真实浏览器中点击验证。
- `SUB-G017`：坐标系必须为右手 `MODEL_XYZ`，同一开关同步控制 SVG 轴标、原点和三维三轴。
- 水平矩形边只能由宽度控制，竖直矩形边只能由高度控制；测试必须同时检查相互垂直的两条边。
- 测量卡必须显示单位和权威来源；投影辅助值不得伪装为模型真值。
- 核心参数表通过不代表选择测量通过，两类门禁必须分别执行。
