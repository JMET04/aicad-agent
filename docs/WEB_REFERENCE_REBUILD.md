# Webpage and image reference reconstruction

See the plugin-owned specification at `agent-plugin/aicad-agent/docs/WEB_REFERENCE_REBUILD.md`.

The core guarantees are: calibrated physical units rather than pixel-derived dimensions, direct SVG DOM evidence when available, one-to-one object bindings, exact text/rotation evidence, bounded collision-avoidance offsets, preserved preview aspect ratio, browser-backed overlap and mojibake checks, and explicit native-AutoCAD limitations.
