# 制造前成本与可用性未闭合事故复盘

日期：2026-10-09。状态：用户终止原项目；后续仅进行离线复查、插件修正与公开脱敏复盘。本文不包含个人身份、地址、付款信息、订单编号、登录链接或密钥。

## 事实与责任

原任务是完整的动作控制发射器与带动画/声音、可选外设控制的接收器，而不只是两种裸PCB。两份裸板订单使用券后含运费0元，且裸板合同/订单操作已经获用户授权。但完整装配方案的价格、供货、功能闭环和全部外部配件尚未确认，就推进到了制造承诺。

因此这不是“完全无授权付款”的错误，也不能因0元就认定没有事故。真正失误是没有在不可逆制造前交代并冻结完整交付物的成本和可用性。用户授权裸板订单、领取券或说继续，并不表示已经接受整套配件预算和未完成的开发风险。时间、开发投入和未来装配风险已存在；实际经济损失没有完整统计，不编造损失金额。

10月7—9日保留原料的既有报价，两套已报价板上件约803.04元，加两块原屏约978.62元，仍缺电池、执行器、线束等完整可装清单及运费；四个原主控就占501.76元，两块原屏175.58元。便宜的异封装主控、异尺寸屏不能焊上现板就算替换成功。几组同规格电阻的条件预算仅能减少约1.10元，尚须试装。不能把这些部分报价叫“完整最低价”。

## 根因

| 失误 | 本次表现 | 长期修正 |
| --- | --- | --- |
| 目标缩小却未重新确认 | 用“免费裸板完成”替代“完整可用系统” | 冻结完整交付物/数量与源绑定成本库存；只有真实明确的裸板范围接受才能使用bare_pcb口径 |
| 成本核验过晚 | 高价/缺货主控和屏在制造后才成为明显阻碍 | 高价大头、MOQ、库存、配套件、装配/工具与运输税费必须在制造承诺前核清 |
| 授权范围混淆 | 裸板合同或操作授权被误视为整套预算接受 | 独立预算记录绑定同一设计、范围、报价集合和具体动作；修改后重新确认 |
| 优惠券驱动流程 | 只关注0元订单，不关注完整结果能否负担 | 即使PCB价0，完整产品缺价/超预算/缺货也阻断制造、付款或用券 |
| 证据等级混淆 | DRC、制造解析、算法样例被当成可用性接近完成 | 分开几何、电气模型、固件逻辑、功能模拟、工程CAM与首件实测，不互相抵偿 |
| 模块通过不等于系统可用 | 独立算法工作，实际固件默认无线关闭 | 核对最终构建配置和准确原生板/固件版本，直接读取受哈希约束的配置，不相信自写“启用”声明 |
| 持续工作掩盖无进展 | 重复查价、生成候选/状态未闭合 | 缺口记录、停止条件、有限安全独立检查；用户终止后保持停止 |

这是代理的工程流程责任，不归咎于用户不会操作浏览器、批准某项动作或要求便宜配件。

## 本次电脑复查：实际运行与边界

在隔离目录重新配置、编译当前固件核心及安装中已有的TF-PSA-Crypto源，GCC 16.1.0、严格警告，CMake/Ninja构建188步成功；CTest实际运行30项全部通过。覆盖：八类手势输入样例/拒绝、数据帧与会话、真实PSA加密与独立oracle、重放防护、存储/启动失败安全、多通道调度、240×240 RGB565渲染、PCM音频、显示/音频流及驱动mock等。未下载或发布第三方密码库，未连接板、配对、写入密钥、烧录或驱动负载。

这只证明相应电脑测试里的逻辑和观测指标。部分测试使用mock，且部分目标合同仍是旧模块基线，并不自动绑定已制造的最新原生板。不能宣布准确原生版本的整套功能通过。

源配置实际检查发现：

- 发射端`target/zephyr/prj.conf`中CONFIG_BT=n；CONFIG_MW_AXIS_MAP_APPROVED=n；CONFIG_MW_C08_005_ACTUATOR_APPROVED=n。
- 接收端`target/receiver-effects-app/prj.conf`中CONFIG_BT=n、CONFIG_I2S=n。候选媒体/音频实现是额外受控路线，不是默认固件已完成功能。
- 发射端安全事件接口存在返回-ENOTSUP的弱实现；接收端启动记录明示无真实radio session。
- 因而当前不能“买齐、焊好就挥棒无线触发动画/声音”。需继续实际无线/配置/安全激活集成及首件测试，但用户已终止，不能擅自把这些缺口修成继续制造任务。
- 电芯额定/体积、保护与温度检测完整性未解决；充电使能不能靠现固件随意控制。30项host测试不覆盖真实充电温度曲线、电源启动/瞬态、续航、EMC、射频距离、屏幕字节顺序、实际I2S、声压或机械焊接。
- 可选外设输出保持禁用，不能直接连接220V。未做或无权威模型的电气模拟记未验证，而非0个错误。
