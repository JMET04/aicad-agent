# aicad-agent 1.17.0

Release date: 2026-08-21

## Trustworthy engineering-domain maturity

- The registry `maturity` field is now a declaration only. Code-owned ceilings,
  non-placeholder executable probes and an exact regular-file size/SHA-256
  evidence closure determine effective maturity.
- Missing, unreadable, linked/reparse, path-escaping, changing or incomplete
  evidence fails closed. A named implementation with a missing or placeholder
  required function does not count as an executable capability.
- Semantic documents, domain reports, experience recall, CLI output and Agent API
  output all expose the same effective decision. Foundation-locked domains remain
  blocked by hard `DOMAIN.G000` before specialist artifact exposure.

## Civil, experience and provider cost controls

- Civil work can reach only a constrained, source-bound review candidate after
  jurisdiction, CRS/datum, survey controls, alignment/profile, drainage,
  utility and geotechnical evidence pass. Production and professional release
  remain false.
- Authority-first experience recall now returns an exact coverage inventory.
  Coverage passes require real `{path,size,sha256,kind}` evidence; candidate
  lessons remain advisory and cannot silently become rules.
- Provider usage reporting includes rough OpenAI and DeepSeek API cost estimates,
  while deterministic offline generation remains the no-key default.

## Operational 2D/3D review console

- Drafting hierarchy remains visible instead of flattening every line to one
  stroke. Text and status content stay inside their bounded panels across desktop,
  tablet and narrow mobile widths.
- The reviewer exposes synchronized 2D and 3D views, including an interactive 3D
  model view where source geometry supports it, without treating projections as
  dimensional authority.

## Release integrity

- Public-plugin synchronization is dry-run by default, repository-bounded,
  rollback-safe and verified after promotion.
- Fresh build, tracked public plugin and staged GitHub plugin must agree on API,
  component and runtime versions plus exact file path/size/SHA-256 closure.
- The package remains an engineering review candidate. It does not grant technical
  acceptance, production release, manufacturing or fabrication authorization.
