# 魔杖接收器动画与音效预览

这些预览直接由接收器固件中的 `mw_pattern_renderer`、
`mw_effect_scheduler` 和 `mw_effect_audio` 导出，不是另画的一套演示素材。

## 快速审查

- `all-effects.gif`：8 种动画同步总览。
- `all-effects.png`：8 种效果静态总览。
- `primary-effects-timeline.png`：火、冰、爆炸在 0/250/500/750 ms 的逐帧变化。
- 每个效果都有 `.mp4`（带声）、`.gif`（循环动画）、`.png`（海报帧）和
  `.wav`（无损 PCM）版本。

## 手势映射

| 效果 | 触发手势 | 文件名前缀 |
|---|---|---|
| 火魔咒 | 顺时针扭转 | `fire` |
| 冰冻魔咒 | 逆时针扭转 | `ice` |
| 爆炸魔咒 | 敲击 | `explosion` |
| 闪电魔咒 | 向左挥动 | `lightning` |
| 护盾魔咒 | 向右挥动 | `shield` |
| 奥术脉冲 | 向前刺出 | `arcane` |
| 治愈魔咒 | 顺时针画圈 | `heal` |
| 传送门 | 逆时针画圈 | `portal` |

## 媒体参数

- 动画：240×240，20 fps，18 帧，900 ms，与 GC9A01 圆屏渲染尺寸一致。
- 音频：16 kHz、16-bit、单声道 PCM；每个预览补静音至 900 ms 以保持声画同步。
- 固件默认音量请求为 35%；全局上限 40%，爆炸音效单独限制为 25%。
- `manifest.csv` 记录每个效果的手势、效果、音频 cue、帧率、时长和实际音量限制。

这些文件证明主机侧渲染与合成输出可重复生成，但不替代真机屏幕色彩、扬声器响度、
失真、功耗和延迟测试；这些物理 HIL 门仍需在首块接收器板上关闭。
