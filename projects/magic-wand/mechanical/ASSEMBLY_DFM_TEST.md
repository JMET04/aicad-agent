# 装配、DFM 与试验计划

## 推荐的原理样机装配顺序

1. 按 `design-parameters.json` 检验四个打印件和 GFRP 来料，隔离超差件。
2. 对空壳执行载架滑入试验；禁止敲击。记录插入力、卡滞位置和拆卸性。
3. 保持 Z=5..30 射频禁布区为空，仅放置后向天线基准模块；电芯不得进入 Z<40。
4. 在未上胶状态装入后端盖和杆连接件，核对总长、同轴性、侧孔基准和可维护性。
5. 用独立胶接试片选定表面处理、混合、胶层、固化和老化流程；未通过前不得给整机永久上胶。
6. 合格试片之后才允许制作一件受控胶接样机，并保留批次、操作者和固化记录。

## DFM 复核

### 打印件

- 握柄壳壁厚 2.0 mm、载架壁厚 1.2 mm 是几何值，不是任何工艺的最小稳定壁厚证明；
- 首选把 B 轴竖直或使用能控制圆度/孔收缩的工艺，并为壳孔、插塞和胶孔做试条；
- 后端盖必须使用非导电、无导电填料/涂层的材料；
- 未建模圆角会造成应力集中和手感问题，原生 CAD 内核增加圆角能力后需另版处理；不得由工厂口头打磨替代受控修订。

### GFRP 与胶接

- 切割必须控制纤维飞边和粉尘，端部封闭/倒钝方案需由材料/工艺负责人确认；
- 连接件孔与杆的胶层空间需用试条确认；
- 不允许用外观完整代替拉拔、扭转和环境老化结果。

### 电子/射频接口

- USB、按键、振动器、线束不得把结构载荷直接传到焊盘；
- IMU 固定面、方向防呆和振动隔离尚未形成原生机械特征；
- 代表性整机必须覆盖握持姿态、人体遮挡和线缆布置的 RF 测试。

## 数字验证顺序

1. 运行 54 项机械受控生成预检并验证源文件哈希；
2. 验证 4 个 3D 特征图与 5 个 2D 图计划；
3. 编译全部 2D 图，核对 DXF/AICAD/SCR/审计/清单；
4. SolidWorks 中逐件执行、保存 SLDPRT/STEP、关闭并重开；
5. 要求每个特征：草图完全约束、错误码 0、单一无故障实体、体积/边界框一致、必需持久引用 0 未解析；
6. 运行 `test_magic_wand_mechanical_package.py`，最后再做只读哈希闭包检查。

## 首件检验与功能试验

| 阶段 | 检查 | 原理样机判定 |
|---|---|---|
| 来料 | GFRP 直径/长度/直线度/表面缺陷 | 记录结果；供应牌号未冻结则不得放行生产 |
| 打印件 | 外径、孔径、长度、壁厚、椭圆度 | 满足显式界限且无裂纹/分层/尖边 |
| 试装 | 插塞和载架手动装拆 | 无锤击、无肉眼损伤、无非预期卡死 |
| 解锁 | Z=72、孔径、凹陷、行程、操作力 | 尺寸满足；松手能机械回位 |
| RF 区 | Z=5..30 禁布检查 | 禁止类别 0 件，电池和 GFRP 间隙达到参数源 |
| 胶接试片 | 拉拔/扭转/温湿老化 | 指标由负责工程师在选胶后冻结，本包不预设通过值 |
| 操作 | 监督下空载手势 | 无松动、异响、尖边；禁止敲击和碰撞试验替代结构评估 |
| 安全边界 | 失电/松手/通信异常 | 机械仅验证按键回位；系统级安全由电子和固件包验证 |

## 工厂沟通结论

本包可用于**报价、工艺咨询和无永久胶接的尺寸样件**，前提是工厂收到本文件并接受“仅原理样机”的水印/锁。不得直接用于永久胶接样机、功能安全样机、儿童产品、认证样机或批量生产。至少完成侧孔原生补模、材料/胶接试验、装配干涉、结构/跌落评估、RF 复核和负责工程师签发后，才可讨论制造放行。
