# Selected standards authority — review candidate

Scope: controlled generation of one metric machined mechanical part. Editions are bound to the canonical AICAD v3 mechanical ledger; this record authorizes generation constraints only, not production release.

- ISO 8015:2011 — GPS fundamentals.
- ISO 14405-1:2025 — dimensional tolerancing.
- ISO 5459:2024 — datums and datum systems.
- ISO 1101:2017 — geometrical tolerancing.
- ISO 22081:2021 — general geometrical and size specifications.
- ISO 13715:2017 — edges of undefined shape.
- ISO 21920-1:2021 — surface texture indication.
- ISO 1:2022 — 20 °C reference temperature for specification and verification.
- ISO 2768-1:1989 — general linear/angular tolerances, invoked as class m.
- ISO 286-1:2010 and ISO 286-2:2010 — limits and fits, invoked for bearing and dowel interfaces.
- ISO 965-1:2026 — metric thread tolerance basis when threaded mating hardware is specified.
- ISO 898-1:2013 — class 10.9 steel mounting fastener properties.
- ISO 16047:2005+Amd 1:2012 — torque/clamp-force test basis.

Project decisions:

- Datum system is A (bottom mounting plane), B (Ø80 bearing-seat axis), C (primary Ø8 H7 dowel axis).
- General tolerance is ISO 2768-m where an individual size/GPS requirement is absent.
- All critical fits, positions, flatness, perpendicularity, coaxiality and surface texture are individually specified and therefore override the general tolerance.
- No retired or withdrawn document is used as sole authority.
